# Teacher Planning Platform - Canonical Pilot Weekly Workflow

## Submission model

Each teaching section produces two different immutable submission types for a teaching week:

1. **Lesson plan submission** - submitted before instruction. It contains the Instructional Planning Framework and Week at a Glance for the week that will be taught.
2. **Completed packet submission** - submitted at Friday closeout. It contains that same week's planning documents plus the completed teacher-authored Weekly Reflection / PLC Discussion.

These are separate administrative records. The following week's lesson plan is never treated as the current week's reflection submission.

## First week

1. From Dashboard, add each teaching section through Course Setup.
2. Confirm class schedule, Curriculum & Pacing, and authoritative course standards mapping.
3. Build the first week's plan.
4. Save, review/print the Instructional Planning Framework and Week at a Glance, and submit the **lesson plan** for each class.

## Every Friday after the first week

1. Complete Friday validation for the week that was just taught.
2. Complete the required teacher-authored Weekly Reflection / PLC Discussion for that same week.
3. Submit Friday closeout. TPP creates the immutable **completed packet** for the current week. It contains the current week's submitted plan/grid plus the current week's reflection.
4. TPP advances to the following week. Reconcile carry-forward instruction and schedule exceptions.
5. Build, review, and save the following week's plan. Print it when required for classroom posting.
6. Submit the following week's **lesson plan** as its own immutable submission.
7. That following week receives a completed packet only after its own Friday validation and reflection are finished.

Each teaching section is planned and submitted separately.

## Administrator review

For a selected week, Administration shows both records for every teacher/course:

- **Upcoming lesson plan** - the pre-instruction submission, with Framework + Week at a Glance.
- **Completed weekly packet** - the end-of-week submission, with Framework + Week at a Glance + Reflection.

Administrators may filter by school, multiple teachers, or course; select individual or all filtered records; and bulk review/download/print either lesson plans or completed packets without mixing the two submission types.

## Data boundary

Use educator, curriculum, standards, schedule, lesson-plan, and class/group-level professional planning information only. Do not enter student names, identifiers, grades, identifiable student work, IEP/504 information, health or discipline information, or other student-specific information.

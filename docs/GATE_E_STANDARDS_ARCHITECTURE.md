# Gate E Standards and AI Architecture

## Status

Locked pilot architecture for the release-blocking Gate E implementation. This document records the current design boundary; it does not expand TPP into student-data or Guided Scholar workflows.

## Comprehensive authoritative catalog

TPP ingests and governs the full current Alabama State Department of Education / Alabama Achieves standards and course-of-study catalog rather than a small pilot-only subset.

The discovery boundary includes every current Alabama academic subject / Course of Study and every current Career and Technical Education cluster / course family that the authoritative state catalogs expose. The implementation must discover newly published logical sources rather than relying on a permanent hard-coded source list.

Additional authoritative issuers may supplement Alabama provenance for a mapped course. For example, Army JROTC retains Alabama Government & Public Administration course/program provenance plus the current U.S. Army Cadet Command JROTC curriculum provenance.

## Source roles

Authoritative source records have explicit roles:

- `course_of_study` — authoritative standards text; may create selectable standard entries.
- `program_guide` — authoritative state course names/codes/catalog provenance; never creates weekly standard entries.
- `supplemental_curriculum` — additional authoritative issuer curriculum/standards for a canonical Alabama course; may create supplemental selectable entries.
- `reference` — governed reference material that is neither an automatic standards source nor a course-listing source.

Pending snapshots may be parsed and reviewed but cannot change the teacher-visible catalog. Course/catalog projection occurs only when a platform administrator approves that exact snapshot.

## Canonical teacher catalog

Source-specific parser output is normalized to a canonical teacher-facing catalog:

`Subject / Career Cluster -> Grade / Course -> standards`

A canonical course can retain multiple provenance relationships:

- primary Alabama standards source;
- Alabama course-listing / Program Guide source;
- supplemental authoritative issuer where applicable.

The teacher does not choose among underlying sources.

## Teacher assignment mapping

Option A is locked for the pilot: one primary canonical standards course per teaching assignment.

At course setup the teacher selects:

1. **Subject / Career Cluster**
2. **Grade / Course**

The teacher-facing course/section name is independent of the standards mapping.

### Correcting a mapping

Teachers may correct an incorrect mapping.

- Before planning exists, the mapping may be changed normally.
- If weekly planning exists, an explicit warning and affirmative confirmation are required.
- Open/unvalidated weekly standards selections from the prior mapping are cleared.
- Other planning narrative remains intact.
- Validated historical weeks retain the exact standards entries, source snapshots, and provenance originally used.
- Mapping corrections apply to the current open/unvalidated context and future planning; they do not rewrite history.

## Weekly primary standards

Once the assignment is mapped, weekly planning loads only standards belonging to that canonical course and its approved source relationships. Cross-course leakage is a release blocker.

The teacher selects the standards that apply to the target week. Each selection stores the exact standard-entry identifier and therefore remains traceable to the exact source snapshot/version.

Authoritative wording is deterministic source data. AI must never write, rewrite, paraphrase, infer, or fabricate authoritative standard text.

## Literacy alignment

Literacy is a cross-disciplinary instructional alignment, not an assertion that every Alabama course has an official embedded ELA standard.

TPP maintains Alabama ELA standards as governed structured data. AI may recommend one or more **existing governed literacy standard IDs** that authentically connect to the selected primary standards and planned instruction.

The model returns identifiers plus rationale/instructional application. The server resolves and displays exact authoritative wording from the governed catalog. If no authentic alignment exists, the model may recommend none.

## ACT Preparation alignment

ACT preparation is a recommended skill connection, not a fabricated course requirement.

When an operationally approved ACT College and Career Readiness Standards reference catalog is available, AI may recommend one or more **existing governed ACT skill IDs** plus a short instructional application. Exact reference wording is resolved from the governed catalog, not generated by the model.

If no meaningful ACT connection exists, the model may recommend none.

## AI planning assistance

Teacher-invoked AI may suggest:

- learning targets;
- Know / Understand / Do;
- activities;
- assessments;
- resources;
- literacy connections from governed Alabama ELA IDs;
- ACT connections from governed ACT IDs where approved;
- other bounded planning fields included in the accepted form.

AI outputs remain visibly draft suggestions. Teachers explicitly accept, edit, or reject them. No AI output silently overwrites saved teacher work.

## Weekly Reflection assistance

Weekly Reflection AI is grounded only in:

- the saved weekly plan;
- finalized Friday validation;
- governed standards/provenance context.

The reflection is a reviewable draft with the same teacher-control contract. It must not invent student performance evidence or request student-specific data.

## Monthly authoritative-source validation

On the first workday of every month, the maintenance path:

1. discovers the complete current Alabama academic and CTE catalogs;
2. records catalog-level `unchanged`, `changed`, `new`, or `missing` evidence;
3. validates every active approved governed authoritative source;
4. records source-level `unchanged`, `changed`, or `unavailable/error` evidence;
5. stages changed/new candidates for human review;
6. never silently replaces an approved snapshot.

If the catalog landing page is unavailable, the failure is recorded and already approved individual sources are still checked where possible. Existing approved standards remain usable for weekly planning.

## Data boundary

TPP remains teacher/curriculum/standards/planning data only for this pilot. No student data belongs in TPP or its OpenAI requests.

The interactive teacher-facing runtime may receive the OpenAI API credential but must not receive the Supabase service-role credential. Privileged catalog/source maintenance runs in a separate maintenance path.

## Future interoperability — architecture only

This release does **not** build Guided Scholar integration, longitudinal student recommendations, class analytics, or student-specific assignment logic.

To avoid future redesign, structured identifiers and relationships should be preserved wherever practical for:

- primary standards;
- literacy alignments;
- ACT skills;
- learning targets / instructional skills;
- source/snapshot provenance.

That preserves future opportunities such as TPP-to-Guided-Scholar assignment/template recommendations and, under a separately governed future student-data architecture, longitudinal-feedback-informed teacher recommendations. These are architectural affordances only and are not part of Gate E acceptance.
